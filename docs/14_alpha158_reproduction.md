# Alpha158 + GBDT 复现：第一次拿到正的样本外 alpha（2026-11）

> 此前七次尝试全部否定。这一次不同：**复现了微软 Qlib 的公开基准**，
> 并在 2021-2026 的真实样本外拿到 IC = +0.0260 (t = +7.89)。

---

## 一、做了什么

| 组件 | 文件 | 说明 |
|---|---|---|
| 数据 | `qcore/qlib_data.py` | 读 `chenditc/investment_data`（Apache-2.0）的 Qlib 二进制格式 |
| 因子 | `qcore/alpha158.py` | 158 个因子，纯 numpy/pandas，截断不变性 0 差异 |
| 模型 | `qcore/gbdt.py` | 纯 numpy 梯度提升树（直方图分裂 + 二阶梯度 + 早停） |
| 基准 | `scripts/benchmark_alpha158.py` | 复现 Qlib 官方 workflow |

**数据规模**：6170 只股票，2000-2026，**含退市股**，点对点 CSI300 成分。

## 三、真实样本外（关键）

### 3.1 不重训（用 2014 年前的模型测 2021-2026）

| 指标 | 数值 |
|---|---|
| IC | +0.0092 (t=+2.43) |
| RankIC | **+0.0018** |

模型陈旧 7 年，排序能力基本消失。

### 3.2 滚动重训（用截至 2019 训练，测 2021-2026）

| 树数 | IC | t | RankIC | ICIR |
|---|---|---|---|---|
| 6（激进早停） | +0.0222 | +6.45 | **+0.0004** | 0.171 |
| **250（不早停）** | **+0.0260** | **+7.89** | **+0.0103** | 0.210 |

**结论：滚动重训后，IC 在 2021-2026 保持 +0.026，t=+7.89。**

---

## 四、一个必须记的技术坑：树太少会毁掉 RankIC

早停在 2020 年验证集上只跑了 **6 棵树**，结果：

```
IC      = +0.0222   （看起来还行）
RankIC  = +0.0004   （排序能力完全消失）
```

原因：6 棵树 × 深度 4 最多产生 90 个不同叶子值，**300 只股票必然大量并列**。
Spearman 对并列敏感，排名信息被并列抹平。

**教训**：树模型的 RankIC 必须检查树数。少于 50 棵时 RankIC 不可信。
不做早停、固定 250 棵后，RankIC 恢复到 0.0103。

## 六、还没解决的问题（不要过早乐观）

### 6.1 换手率与成本

IC 0.026 是**日频**信号。按 A 股 19.28bps 往返成本，日频调仓年化拖累约
`250 × 19.28bps × 换手率`。若换手 50%，年化成本 24%——**IC 0.026 撑不住**。

必须做**低换手版本**：
- 持有期拉长到 5-20 日
- 或按 rank 分档 + 缓冲带（只换掉跌出前 N% 的）
- 或用 Qlib 的 TopkDropout 策略（每天最多换 5 只）

### 6.2 RankIC 只有 0.0103

IC 0.026 但 RankIC 0.0103 说明：**线性预测能力有，但排序能力弱**。
对选股（需要排序）来说，0.0103 是偏低的。

Qlib 官方 RankIC 0.0469，我们只有 22%。差距可能在：
- 我们只有 158 因子（可能某些实现是近似）
- 我们没用 LightGBM 的完整特性（如 feature bundling、leaf-wise 生长）
- 数据口径差异（社区数据 vs 官方数据）

### 6.3 只测了 CSI300

大盘股流动性好但 alpha 少。Qlib 在 CSI500 上的 LightGBM IC=0.0399。
小盘股可能 alpha 更多，但成本更高。

## 八、可复现命令

```bash
# 数据（一次性，544MB）
# https://github.com/chenditc/investment_data/releases

# 复现 Qlib 同期
python scripts/benchmark_alpha158.py --horizon 1 --stocks 300 \
    --test-start 2017-01-01 --test-end 2020-12-31

# 真实样本外（滚动重训）
python scripts/benchmark_alpha158.py --horizon 1 --stocks 300 \
    --train-end 2019-12-31 --valid-start 2020-01-01 --valid-end 2020-12-31 \
    --test-start 2021-01-01 --test-end 2026-11-06 \
    --trees 250 --early-stop 0
```

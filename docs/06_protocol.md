# 你给代码，我给你前景 —— 评估协议 v1.0

> 这份文档定义我们之间的工作方式。核心原则只有一条：
> **所有判断必须在结果揭晓之前写下来，并且写清楚"什么情况下算我错"。**

---

## 一、你可以怎么给我代码

| 方式 | 怎么做 | 我会得到什么 |
|---|---|---|
| **片段** | 直接贴函数/类 | 只能做静态分析 + 小样本试跑，结论强度低 |
| **单文件** | 给我路径或内容 | 静态分析 + 用真实数据跑通 |
| **仓库** | 给我目录/仓库地址 | 全流程：体检 → 实跑 → 前景测算 → 预登记 |
| **只是想法** | 描述策略逻辑 | 我先写成最小可跑版本，再走同一套流程 |

**无论哪种，我不会先夸再算。顺序永远是：先量，后说。**

---

## 二、我给你的东西固定是这五块

### 1. 静态体检（10 分钟）
- 依赖能不能在这个环境装（本机只有 numpy/pandas，无 scipy/sklearn/talib）
- 数据要求（什么频率、多少历史、要不要付费源）
- **泄漏扫描**：全样本 `mean/std/quantile`、`shift(-n)`、`bfill`、未来 join（复用 `audit/leak_scan.py`）
- 有没有测试、能不能复现

### 2. 能力定位（一句话）
它到底是「信号生成」「组合优化」「执行」还是「回测框架」。
**很多代码自称策略，实际只是回测器** —— 这一步就是拆穿它。

### 3. 实跑数据（唯一可信的证据）
在真实 A 股/美股数据上跑，输出：

| 指标 | 口径 |
|---|---|
| 横截面 Rank IC | 每日 Spearman，**HAC 标准误（滞后 h−1）** |
| IC 的 t 值与 95% CI | 重叠样本已校正 |
| 多空年化 / Sharpe / 回撤 | 非重叠 h 日调仓，扣双边成本 |
| Deflated Sharpe | 扣掉「试了多少次」的运气 |
| 分年度 IC | 看是不是只有某两年好用 |
| 换手与成本拖累 | 成本吃掉多少 IR |

**没有这些数字的"前景"，一律是讲故事。**

### 4. 前景与空间（`qcore/forecast.py`）

用 Grinold 基本法则把话说死：

```
IR ≈ IC · √BR        BR = 持仓数 × 年调仓次数
```

然后把"未来空间"拆成四项，**每项单独给区间和前提**：

| 维度 | 现在 | 空间 | 要成立需要什么 |
|---|---|---|---|
| IC | 实测值 | 到同类上限还差多少 | 补什么信号、相关性要降到多少 |
| 广度 | N×年调仓次数 | 加股票/加频率 | 流动性够不够、成本会不会爆 |
| 成本 | 每年吃掉多少 IR | 降换手能省多少 | 信号持续性要多久 |
| 容量 | 按成交额倒推 | 能装多少钱 | 冲击成本非线性 |

输出永远是**三档情景**（悲观/中性/乐观），每档写明"什么条件下才成立"。
**不给单点预测，不给"预计年化 XX%"这种话。**

### 5. 预登记可证伪条件（`qcore/claims.py`）

每条判断在写下的瞬间就登记进台账：

```bash
python -m qcore.claims add \
  --subject "APB v1" \
  --statement "补入基本面信号后，h=5 横截面 IC 能转正" \
  --metric "ic_h5" --threshold 0.0 --comparator ">" \
  --review-by 2027-06-30 \
  --falsifier "若 6 个月后滚动 250 日 IC 均值仍 <= 0，则此判断错误"
```

登记后**判断内容不可修改**，只允许追加验证结果。

## 三、你怎么纠正我（三种方式，从轻到重）

### 方式 A：给数字
```bash
python -m qcore.claims review --cid abc123 --actual 0.012
```
系统按登记的阈值自动判定 confirmed / refuted。

### 方式 B：直接下结论 + 理由
```bash
python -m qcore.claims review --cid abc123 --verdict refuted \
  --reason "实际跑出来 IC 是 -0.01，你说的转正没发生；而且你漏了停牌复牌的影响"
```
**你的判定优先于自动判定。** 理由会被永久保留，作为我以后改进的依据。

### 方式 C：给事实，让我自己改
"这个池子里 601607 后复权有负价" —— 这类事实我不辩解，直接改代码、改结论、
并把被推翻的旧判断标成 refuted。

> 审计员已经用方式 C 推翻过我一次：我断言"后复权永不越零"，
> 他给出 5 只股票 354 根非正 bar 的证据，我当场改了结论并写进 docs/03_limitations.md。

## 五、一次真实示例（用本项目自己的数字）

假设你把 APB 这套代码给我，我会这样回答：

**实测（283 只 / 2013-2026 / h=5）**

| 项目 | 数值 | 解读 |
|---|---|---|
| 横截面 IC | **−0.0184** | 方向系统性做反 |
| HAC t | **−2.47** | 95% CI 全在 0 以下，不是噪声 |
| 原始方向命中率 | 48.5% | 低于抛硬币 |
| 多空年化（扣成本） | +4.5%，t=0.59 | 不显著 |
| Deflated Sharpe | 0.008 | 完全没过 |
| 学习器 vs 等权 | 无显著差异 | **学习器无效** |
| 有效独立信号 | 33.1 / 73 | 21% 是镜像对，不是"73 个专家" |

**前景判断**

> 这套代码当前**没有可用的选股能力**。讨论"未来空间"的前提是先解决方向问题：
> 要么证明这个负 IC 是真实的反转效应（需独立样本再验一次），
> 要么换特征（基本面/资金面/事件面），而不是继续在技术指标里调参。
>
> 乐观情景（IC 达到技术类上限 0.030）下 IR 约 0.67 —— 但那需要 IC 从 −0.018
> 变成 +0.030，跨度 0.048，**这不是调参能到的，是换信息源才能到的**。

**预登记的四条可证伪条件**

1. 补入基本面信号后，滚动 250 日 IC 转正（HAC t>2）—— 6 个月后复核
2. 扣双边成本后净 IR > 0.3 —— 12 个月后复核
3. 有效独立信号数 > 45（镜像对占比 < 15%）—— 重构后复核
4. 相对「当日池等权」的超额 > 0（而非相对沪深300）—— 立即生效

第 4 条是审计员逼出来的：池子自带约 +22pp/年 的生存者偏差，
**拿沪深300 当基准会让任何做多策略都显得很厉害**。

## 六、我不做的事

- ❌ 不承诺收益、不写"预计年化 XX%"
- ❌ 不在没有 HAC 校正的情况下报 t 值
- ❌ 不用样本内最优参数当结论
- ❌ 不把"回测好看"等同于"能赚钱"
- ❌ 不在你纠正我之后辩解 —— 只记账、只改

## 七、你需要知道的两个前提

1. **我给的是概率区间，不是预言。** 所有"前景"都是条件概率，
   条件写在每个情景的 `premise` 字段里。
2. **样本外永远未知。** 即使所有检验通过，实盘仍可能失败 ——
   所以永远先用模拟盘跑 3-6 个月，再谈实盘（`qcore/paper.py` 就是干这个的）。

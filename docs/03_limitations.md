# 03 — 缺陷、局限与失效条件（独立审计报告）

> 作者：独立审计（红队）· 审计对象：`qcore/` 全链路
> 审计原则：**不负责让系统跑通，只负责证明它有没有作弊。**
> 本文所有数字均为本机实测（数据区间 2015-01-05 ～ 2026-11-06，样本 2877 交易日 × 39 只 × 73 信号），
> 每条结论都附可复现命令。凡未实测的，明确标注"未验证"。

---

## 0. 一句话结论

**工程纪律是干净的，但系统目前没有 alpha。**

- 未来函数：**未发现**。截断不变性检验 3 个日期全部逐位一致（差值 `0.000e+00`，容差 1e-12），
  且负对照证明该检验有抓漏能力。
- 但走样外 `mean Rank IC = -0.0069`（t = -1.25，2852 天，90640 个观测），
  方向命中率 `0.4981` —— **低于抛硬币**。
- 因此：**"没作弊"和"能赚钱"是两件事。本系统目前通过了前者，没通过后者。**

这是本审计最重要的结论。任何"回测年化 XX%"的说法，都必须先解释为什么 IC ≈ 0。

## 1. 致命局限 #1：样本内没有可测的 alpha

| 指标 | 实测值 | 判读 |
|---|---|---|
| mean Rank IC (h=5) | **-0.0069** | 符号为负，量级≈0 |
| IC t 值 | **-1.25** | \|t\|<2，**统计上与 0 不可区分** |
| 方向命中率 | **0.4981** | 低于 0.5 |
| 有效样本 | 2852 天 / 90640 观测 | 样本量足够，不是"样本太少所以测不出" |

- 90640 个观测下，若真有 IC=0.02 的微弱 alpha，标准误约 `0.2959/√2852 ≈ 0.0055`，
  应该能测出 t≈3.6。**测不出，就是没有。**
- 安慰剂检验交叉印证：把信号换成随机符号后 IC = `+0.0014`（random_dir）/ `+0.0028`（sign_flip_day），
  与真实信号的 `-0.0069` **在噪声范围内无法区分**。
- 参数敏感性交叉印证：18 组参数（h/ρ/κ/η/τ/ε 各 3 档）的 IC **全部落在 [-0.0179, -0.0018]**，
  **没有任何一组参数能让 IC 转正**。

> **必须写进最终报告的话**：学习器 + 73 个技术信号，在这份样本上没有产生可测的横截面预测力。
> 如果报告里出现正的超额收益，那它来自**生存者偏差**（见 §2）或**成本假设**（见 §5），不是来自信号。

复现：
```bash
python audit/placebo.py --reps 4 --top 40
python audit/sensitivity.py --top 40
```

## 2. 致命局限 #2：生存者偏差（已量化）

### 2.1 偏差来源

`qcore/data.py:get_pool()` 用东财 `f20`（**今日**总市值）排序决定下载哪些股票。
这意味着股票池 **100% 是"活到今天并且今天还很大"的公司**，退市、被并购、长期衰落的一个都没有。

### 2.2 偏差方向与量级（实测）

等权持有当前池子 vs 沪深300，价格用后复权、剔除近零价 bar、收益 winsorize 到 ±21%：

| 区间 | 股票数 | 年数 | 池子等权 CAGR | 沪深300 CAGR | **超额** |
|---|---|---|---|---|---|
| 2020-01-01 起 | 70 | 6.8 | **+21.57%** | -0.35% | **+21.9 pp/年** |
| 2022-01-01 起 | 75 | 4.8 | **+19.62%** | -3.91% | **+23.5 pp/年** |

**结论：这个池子自带约 +22 个百分点/年的"白送"收益。**
任何做多为主的策略，其"超额收益"必须先扣掉这一项才有意义。
一个年化 10~15% 的策略在这个池子上其实是**跑输**等权基准的。

### 2.3 点对点选池（UNIV 掩码）目前是**空转**的

`qcore/dataset.py` 用 `amount.rolling(60).mean()` 后按当日横截面排名取前 `n_univ=100`，
口径本身是因果的（滚动 + 当日横截面，未用全样本分位/归一），**这部分实现正确**。

但实测：`N = 39 < n_univ = 100`，掩码恒为真，**从未生效**。

```
UNIV shape (2877, 39)  True share = 0.8297
=> UNIV mask is INERT (N <= n_univ, never binds)
```
那 0.8297 只是 `traded` 的贡献，不是选池的贡献。

**这条修复要等下载池（300 只）远大于 n_univ（100）时才有意义。**
在那之前，报告里不能声称"已修正生存者偏差"——只能说"已实现机制，尚未生效"。

### 2.4 无法消除的残余偏差

即使 UNIV 生效，也只解决"**当日该选谁**"，不解决"**当年这些公司是否存在**"。
后者需要包含已退市股票的历史成分股名单，本项目的免费数据源拿不到。
**残余偏差方向恒为向上，量级与池子构造方式强相关，无法从样本内部估计。**

## 3. 复权口径踩坑记录（工程日志）

这是本项目**最危险的一次**数据缺陷，差一点让全部回测数字变成垃圾。

### 3.1 现象

东财 `fqt=1`（前复权）是**减法复权**：`price_qfq = price_raw − 累计分红`。
对高分红、长历史的股票，累计分红超过早期股价 → 价格被压到 0.01，甚至**负数**。

601088（中国神华）直接对比（同一接口，只改 fqt）：

| 日期 | fqt=1 close | fqt=1 pct_chg | fqt=2 close | fqt=2 pct_chg |
|---|---|---|---|---|
| 2011-12-30 | 1.07 | +64.62% | 27.25 | +1.57% |
| 2012-01-04 | 0.34 | -68.22% | 26.52 | -2.68% |
| 2012-01-05 | 0.03 | -91.18% | 26.21 | -1.17% |
| 2012-01-06 | 0.01 | -66.67% | 26.19 | -0.08% |
| **2012-01-09** | **1.75** | **+17400.00%** | **27.93** | **+6.64%** |

全历史 `min(close)`：**fqt=1 = −9.55** vs **fqt=2 = +16.63**。

### 3.2 污染规模（修复前，79 只缓存全量统计）

| 项目 | 数量 | 占比 |
|---|---|---|
| 非正价格 bar | 60677 / 290855 | **20.86%**（41/79 只股票） |
| close < 1.0 的 bar | 14901 | 6.44% |
| close < 0.2 的 bar | 3719 | **1.61%**（39/79 只） |
| 单日 \|涨跌幅\| > 21%（A股不可能） | **4023** | 最大 +17400% |
| 其中 2010–2015 年占比 | 3362 / 4023 | **84%** —— 正好是训练样本主体 |

### 3.3 为什么是"致命"而不是"瑕疵"

1. §0.1.2 收益口径 `r_h(t) = open(t+1+h)/open(t+1) − 1` 在污染区输出 ±10000% 级假收益。
2. 学习器 `y_s = clip(dir·r/(σ_s·√h), −C, C)`，`clip_C=3` 会把这些假收益**截断成满格 ±3**，
   等于**系统性地给噪声最高奖励**。`σ_s` 用 ATR，近零价处 ATR→0 → 除零/爆炸。
3. **`pct_chg` / `amplitude` / `change` 三个"接口直给"字段也是从同一条坏序列算的**
   （2012-01-09 接口自己返回 `pct_chg=17400.00`），所以"接口直给所以安全"这个假设是错的。

### 3.4 修复与验证

- `qcore/data.py`：`ADJUST = 2`（后复权）；缓存文件名改为 `{code}_h{adjust}.csv`，
  新旧口径物理隔离；`pct_chg` 改为本地 `close` 重算，不再信任接口字段。
- 修复后实测（300 只，1151136 根 bar，回测窗口 2013+）：
  `窗口内非正价格 = 0`、`窗口内 close<0.2 = 0`、`窗口内无法解释的异常涨跌幅 = 0`。

### 3.5 ⚠️ 修正一个我自己的过度断言：后复权**也会**越零

我最初在报告里写"后复权是乘法复权，永不越零"。**这个说法是错的**，必须更正：

实测 300 只 hfq 缓存，仍有 **5 只股票**出现非正价格，共 **354 根 bar**：

| 股票 | 非正 bar 数 | 区间 | min(close) |
|---|---|---|---|
| 601607 上海医药 | 268 | 2005-03 ~ 2006-06 | −1.84 |
| 000408 藏格矿业 | 80 | 2005-03 ~ 2006-08 | −1.43 |
| 000425 徐工机械 | 3 | 2005-07 | −0.06 |
| 600674 川投能源 | 2 | 1994-07 | −0.18 |
| 600673 东阳光 | 1 | 1994-07 | +0.06 |

另有 27 根 `0 < close < 0.2` 的 bar，同样分布在这些股票的早期段。

**含义**：东财的 fqt=2 在个别"缩股/重组"类股票上也不是纯乘法口径，
不能把 `ADJUST=2` 当成"绝对安全"。正确的表述是：
**后复权把污染规模从 20.86% 降到 0.03%，并且在回测窗口内归零，但不是零风险。**

**影响评估**：这 354 + 27 根 bar 全部落在 **2013 年之前**，
而 `build_panel` 有 `close > 0` 过滤、回测起点为 2013，
所以**当前回测窗口不受影响**。但这意味着：
1. 若将来把 `start` 提前到 2005 年之前，这些股票会立刻带入假收益；
2. 每扩一次股票池，都必须重跑 `tests/test_no_lookahead.py` 的 L4 —— 不能假定"上次干净这次也干净"。

复现：`python tests/test_no_lookahead.py` 的 L4 项（会打印窗口内/窗口外的分流计数）。

## 4. 停牌/复牌的结构性跳变（尚未处理，建议加）

**这是目前数据层唯一已知的、会污染 `RET` 的残余问题。**

A 股长期停牌（重组、股改、借壳）后复牌首日**没有涨跌幅限制**，且价格常因股本置换发生结构性跳变。
这不是经济收益，但会被当成收益喂进学习器。

实测（300 只 hfq 缓存，停牌缺口 > 15 自然日）：

| 项目 | 数值 |
|---|---|
| 复牌事件数 | **176** 次（99 只子样本统计） |
| 涉及股票 | 52 / 99 只 |
| 复牌日平均 \|涨跌幅\| | **9.34%**（正常日约 1.5%） |
| 复牌日中 \|涨跌幅\| > 21% | 7 次 |
| 结构性跳变总数（300 只，含窗口外） | **38** 次 |
| 极端案例 | 000776 广发证券，停牌 **1212 天**（S延边路借壳），复牌 **+394.3%** |
| 更极端 | 600674 川投能源 **+622.2%**、000425 徐工机械 **+400.0%**（均在 2013 年前） |

**建议**（属 `qcore/dataset.py`，非审计可改）：构造 `RET[h]` 时，把
"入场日或出场日处于停牌缺口边界"的样本置为 `NaN`，或至少把 `|r| > 50%` 的复牌样本剔除。
否则这些假收益会以 `clip_C` 满格的形式进入权重更新。

## 5. 成本与滑点假设

| 项目 | 当前假设 | 现实 | 风险 |
|---|---|---|---|
| 双边成本 | `cost_bps = 10`（即单边 5bp） | 佣金 ~2.5bp/边 + 印花税 10bp（仅卖出）+ 过户费 | **偏乐观** |
| 滑点 | 隐含为 0 | 小盘股/情绪股开盘滑点常 10~30bp | **严重低估** |
| 成交价 | `OPEN[t+1]` | 一字涨停/跌停时**根本买不到** | 未建模 |

- 若按更现实的双边 30bp（佣金+印花税+滑点），年换手 20 次即吃掉 **6%/年**。
  在一个 IC≈0、超额全靠生存者偏差的系统上，这个成本足以把任何"正收益"变成负。
- **一字板未建模**：`VALID` 只看"有价格且成交量为正"，没有识别涨跌停封板。
  策略若偏向动量，会系统性地"买在买不到的位置"，回测高估。

## 6. 信号同质性（已量化）

73 个信号，表面上"专家很多"，实际独立信息远少于此。

| 度量 | 数值 | 说明 |
|---|---|---|
| 信号数 S | 73 | |
| 发声率（非 0 占比） | 中位数 **5.2%**，最小 0.6%，最大 99.2% | 绝大多数信号大部分时间沉默 |
| 无条件两两相关 | 均值 0.023 | **被稀疏性稀释，不能用来判断同质性** |
| **条件相关**（仅在两个信号同时发声时） | 均值 0.103，中位 0.048，**p90 = 0.950** | 真正同质的地方 |
| 条件 \|corr\| > 0.5 的信号对 | **37.1%** | |
| 条件 \|corr\| > 0.8 的信号对 | **23.7%** | 近乎重复 |
| 条件 corr < −0.2 的信号对 | **21.1%** | 互为镜像（如 RSI 超买 vs 超卖） |
| 有效独立信号数（参与率 `(Σλ)²/Σλ²`） | **33.1 / 73** | 约 45% |
| 第一主成分占比 | 10.3% | |

**判读**：
- 无条件相关 0.023 会误导人以为"信号很分散"。真相是：一旦同时发声，
  **近四分之一的信号对几乎是同一个信号（或它的镜像）**。
- 实际有效专家约 **33 个**，不是 73 个。学习器在 73 维上分配权重，
  等于给了噪声 40 个额外维度 —— 这是权重集中度虚高、IC 被稀释的结构性原因。
- 21% 的镜像对（+1/−1 语义相反）意味着：如果学习器把它们都学成同号，
  等于**同一信号被重复计入两次**，投票被放大。

复现：`python -c` 见 §11 脚本片段。

## 7. 样本期结构

- **区间**：2015-01-05 ～ 2026-11-06（2877 交易日）。起点 2015 年初正好在 2014–2015 杠杆牛顶部附近。
- **覆盖的市场状态**：2015 股灾、2016 熔断、2018 单边熊、2020 疫情、2021–2024 长熊、2025–2026 反弹。
  从 regime 多样性看是够的（4 档都有样本）。
- **但**：`build_panel(min_bars=500)` 会把历史不足的股票静默跳过，导致**各股样本起点参差**，
  早期横截面只有 26~30 只股票（实测 L3 检验中 `common=26/39`）。
  **横截面只有 26 只时，Rank IC 的估计噪声极大**，早期年份的 IC 不应单独解读。
- 2026 年是数据末端，最近 1 年样本在"训练/评估"上容易被当成"样本内"，
  任何"最近表现很好"的结论都应视为未经验证。

## 8. 参数搜索本身的过拟合风险

### 8.1 当前状态：无孤峰，但**结论无效**

单参数扫描（其余固定默认）：

| 参数 | 值 → mean IC | 判定 |
|---|---|---|
| horizon | 1: -0.0018 / 5: -0.0069 / 20: -0.0179 | 单调，非孤峰 |
| decay_rho | 0.99: -0.0071 / 0.995: -0.0069 / 0.999: -0.0070 | 几乎不动 |
| kappa | 4: -0.0069 / 8: -0.0069 / 16: -0.0071 | 几乎不动 |
| eta | 0.01: -0.0069 / 0.02: -0.0069 / 0.04: -0.0069 | 几乎不动 |
| tau | 1.0: -0.0073 / 1.5: -0.0069 / 2.5: -0.0064 | 单调 |
| eps_explore | 0.01: -0.0070 / 0.03: -0.0069 / 0.1: -0.0069 | 几乎不动 |

**全部 \|IC\| < 0.02，且无一转正。**

> **必须说清楚**：这里"没有孤峰"**不代表稳健**，而代表"**每个参数值都一样没用**"。
> 敏感性分析只有在指标"活着"的时候才能证明稳健性；指标恒为 0 时，
> 平缓 = 均匀无效。把这条写成"参数稳健"是自欺欺人。

### 8.2 未来真正需要防的过拟合

一旦系统有了非零 alpha，以下风险会立刻显现（现在因为 IC≈0 还没暴露）：

1. **多重检验**：73 信号 × 6 参数 × 3 档 = 1314 种组合，挑最好的必然过拟合。
   需要 White's Reality Check / Deflated Sharpe 之类的校正，当前**没有**。
2. **单参数扫描不等于联合稳健**：参数间可能强交互（如 τ 与 ε 都控制集中度）。
   当前只做单参数，**未做联合网格**。
3. **参数是用同一段样本选的**：`CONFIG` 的默认值来自人工设定，
   若后续用这段样本调优，评估就不再是走样外。
4. **评估窗口重叠**：h=5 的样本每 5 天重叠，IC 的 t 值需要重叠校正（当前按日独立算，**偏乐观**）。

## 9. 这个系统在什么情况下会失效

按"最可能先发生"排序：

1. **横截面变窄时**（池子只剩 20~30 只）：Rank IC 噪声主导，权重学习变成拟合噪声。
   本审计实测早期年份就是这个状态。
2. **regime 切换快于学习器适应时**：`decay_rho=0.995` 的半衰期约 138 次更新，
   叠加 `gamma_n0=60` 的 regime 收缩，意味着新状态要 ~100+ 次对账才被"认账"。
   若风格 2~3 个月切换一次，学习器永远在追上一个 regime。
3. **成本 > alpha 时**：IC≈0 的现状下，任何换手都纯亏（见 §5）。
4. **涨跌停封板时**：动量类信号会系统性地给出"买不到"的信号，实盘与回测背离。
5. **池子被重新定义时**：换 `get_pool` 的 top_n 或 `n_univ`，
   生存者偏差量级立刻变化，历史结论不可迁移。
6. **信号族被扩充时**：新增高相关信号会稀释权重（§6），且加剧多重检验问题。

## 10. 审计方法学 —— 以及**本审计自身的局限**

诚实地说，红队也可能漏。以下是我这个审计**做不到**的事：

| 检验 | 覆盖 | **未覆盖** |
|---|---|---|
| 截断不变性 (L1/L3) | engine + learner + dataset 在 **3 个日期**上的因果性 | 只验 3 天，不是每一天；未验 `metrics/backtest/paper` 的输出 |
| 负对照 (L2) | 证明检验能抓 `shift(-1)` 型泄漏 | 不能证明能抓**更隐蔽**的泄漏（如跨股票信息串用） |
| 静态扫描 | `shift(-n)/bfill/center=True/iloc[i+k]/全样本统计` | 抓不到**语义级**泄漏（如用当日涨停家数当特征却用了收盘后才公布的数据） |
| 安慰剂 | 评估链路无泄漏 | IC≈0 时**无法区分"无泄漏"与"无 alpha"**（已标注 INCONCLUSIVE） |
| 敏感性 | 单参数 3 档 | 未做联合网格、未做多重检验校正 |

- `qcore/metrics.py` / `backtest.py` / `report.py` 只做了静态扫描，**未逐行复核**其指标口径

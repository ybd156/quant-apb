# 风险与机遇分析

> 本文所有数字都来自本仓库的实测，不是估计。可复现命令写在各节末尾。
> 写作时间：2026-11，样本：283 只 A 股 / 2013-2026 / 主周期 5 个交易日。

---

## 结论先行

**这套系统目前的主要价值不是"发现机会"，而是"量化风险"。**

实测结果：73 个技术信号在 A 股大盘股 5 日尺度上**没有可用 alpha**，且方向系统性偏反
（IC −0.0185，HAC t = −2.48）。但同一套基础设施测出了三条真正有价值的线索：

| 线索 | 证据强度 | 状态 |
|---|---|---|
| 非流动性溢价（amihud） | IC +0.026 (t=4.16)，五分位价差 **+0.57% (t=5.94)** | 双指标通过，最可信 |
| 行为因子整体 | 10 个因子方向全部符合文献，6 个 \|t\|>2 | 方向可信，但尾部不一致 |
| 政策事件的"利空出尽" | 集采→医药 h=5 反向 **t=−4.78** | 样本仅 5，待扩样本 |

**换句话说：技术指标这条路基本走到头了，人性与事件这两条路才有增量。**

## 一、系统的风险（按严重度排序）

### R1 ★★★★★ 当前没有 alpha，且方向是反的

| 指标 | 数值 | 判读 |
|---|---|---|
| 横截面 Rank IC (h=5) | **−0.0185** | 方向系统性做反 |
| HAC t 值 | **−2.48** | 95% CI 全在 0 以下，不是噪声 |
| 原始方向命中率 | 48.4% | 低于抛硬币 |
| 多空年化（扣 19.3bps） | +4.0%，t = 0.53 | 不显著 |
| Deflated Sharpe | **0.008** | 扣掉"试了 73 个信号"后归零 |

**为什么这是最高级别的风险**：它意味着**任何基于当前信号的仓位决策，期望收益都不为正**。
Meta 层能把它翻正（命中率 48.5% → 50.7%），但翻正后的 IC t 只有 1.73，**还没到可以下注的程度**。

### R2 ★★★★★ 生存者偏差 ≈ +22pp/年

用"今天的市值排名"筛历史股票，等于事先知道哪些公司活到了今天。
实测：当前池等权 vs 沪深300，2020 年起 **+21.57% vs −0.35%**。

**这会让任何做多策略看起来都很厉害**——而 IC 检验同时显示"没有预测力"。
两者并不矛盾：好看的部分全部来自"我事先知道这 283 家公司今天还很大"。

**缓解**：`Panel3D.UNIV` 掩码按当日 60 日均成交额排名取池。但要注意：
当 N < n_univ 时掩码恒真、等于没生效。**报告里不能声称"已修正"**。

### R3 ★★★★☆ 信号同质性：73 个专家实际只有 12 个独立方向

| 指标 | 数值 |
|---|---|
| 按权重算的有效独立数 | 69.6 |
| **按相关性算的有效独立数** | **12.1** |
| 镜像对占比（\|ρ\|>0.8 且语义相反） | 21% |
| 条件相关 p90 | 0.95 |

"73 个专家投票"是错觉。学习器实际是在 12 个方向 + 大量噪声里挑。
**这也解释了为什么加权平均救不了方向问题**——它们本来就指向同一个方向。

### R4 ★★★★☆ 成本会吃掉一切（分市场差异巨大）

| 市场 | 往返成本 | 5 日调仓 70% 换手的年化拖累 |
|---|---|---|
| A 股 | 19.28 bps | **6.80%/年** |
| 美股 | 3.28 bps | 1.16%/年 |
| 港股 | **38.17 bps** | **13.47%/年** |

港股的杀手是**双边 0.1% 印花税**。同一个策略在 A 股能活，搬到港股可能直接亏死。

**极端案例**：1 分钟频率实测——毛命中率 33.5%，每笔 −0.11bps；
扣 19.28bps 往返后每笔 **−19.39bps**，年化成本拖累 **10,929%**。
1 分钟平均绝对波动只有 8.16bps，**比分母小一个数量级**，调参救不了。

### R5 ★★★★☆ 多重检验：好看了也可能是运气

56 个政策事件 × 若干板块 × 3 个周期 ≈ 200 个格子。噪声系综实测：
**每格 5.6% 假阳性**。所以"某板块在某个周期显著"这句话，**必须先过 Deflated Sharpe / Bonferroni 才能说**。

### R6 ★★★☆☆ 数据源风险（已踩过的坑）

| 问题 | 实测 | 现状 |
|---|---|---|
| 东财 `fqt=1` 是减法复权 | 601088 最低价 **−9.55**，异常 bar 639 个 | 已改 `fqt=2` |
| 后复权仍非零风险 | 300 只里 5 只越零（354 根非正 bar），全在 2013 年前 | 数据守卫已加 |
| 东财后复权 ≠ 腾讯/新浪 | 收益率系统性差 **13bp**（腾讯与新浪彼此只差 2bp） | 三档判定标 `basis_mismatch` |
| 美股 `amount` 2017-07 前恒为 0 | AAPL 9282 根里 6936 根 | 已转 NaN，禁止用它排序 |
| 停牌复牌跳变 | 单日 +394%、+622% | `RET` 在缺口处置 NaN |

**最危险的不是已知的错，而是"看起来对"的错**——比如把缺失当零成交。

### R7 ★★★☆☆ 过拟合：参数不敏感反而是坏消息

18 组参数（h / ρ / κ / η / τ / ε 各 ±50%）的 IC 全在 [−0.0179, −0.0018]。
**没有一组能把 IC 转正** —— 说明不是"参数没调好"，是**信号本身没有信息**。
这种情况下继续调参，等于给噪声加权。

### R8 ★★☆☆☆ 工程风险

- 预测台账与 `data/state/` **不可再生**：丢了等于失忆，历史对账无法重建。
- 单机部署无监控：进程挂了不会告警。
- 数据接口随时可能变（东财已改过多次字段与限流策略）。

## 二、系统的机遇（按证据强度排序）

### O1 ★★★★★ 非流动性溢价：唯一双指标通过的因子

| 指标 | 数值 |
|---|---|
| 秩相关 IC | +0.0258（t = **+4.16**） |
| 五分位价差 Q5−Q1 | **+0.566% / 5 日**（t = **+5.94**） |
| h=20 时 | IC +0.0513（t = +4.08） |

**为什么可信**：① 秩相关与价差方向一致（其他因子都不一致）；
② 有明确经济逻辑（Amihud 2002 流动性溢价）；③ 不依赖技术图形，是结构性特征。

**风险**：非流动性 = 小市值 + 低成交，**与市值因子高度共线**，
且真实交易时冲击成本会吃掉一部分（本模块的 `impact_bps` 有 sqrt 模型）。
**必须先做市值中性化再上线**。

### O2 ★★★★☆ 行为因子整体方向全部符合文献

10 个因子里 **10 个方向与文献预测一致**——这本身是对理论与实现的双重验证。
但只有 amihud 同时通过价差检验，其余（MAX / 偏度 / IVOL / 换手）**秩相关显著但尾部价差反向或不显著**。

**这个反差本身就是重要信息**：说明这些效应集中在分布中段，
或者被小市值/波动率效应在尾部盖过。**不能只看 IC 就下单**。

### O3 ★★★★☆ 技术 × 行为：负相关 −0.43，理论上可叠加

| 组合 | IC | t |
|---|---|---|
| 技术（原） | −0.0185 | −2.48 |
| 技术（meta 翻正） | +0.0154 | +1.84 |
| 行为 | +0.0352 | +5.14 |
| 各半 | +0.0288 | +3.89 |

负相关说明**信息确实互补**，但等权相加是稀释（信噪比差 2 倍）。
正确做法是按信息含量加权——`qcore/combo.py` 已实现因果多元组合，但**当前版本数值不稳定，需修**。

### O4 ★★★☆☆ 情绪反向指标：只能前向验证

股吧情绪抓取已跑通（164–170 条/股）。实测样本：
`000001` 触发"极度一致看多"（consensus 0.65，bull 38 vs bear 8）。

**但必须说清楚**：股吧只能抓当下、不能按历史日期翻页 ⇒ **无法回测**。
唯一诚实的验证方式是前向采集 3-6 个月，看"极端一致"之后是否真的跌。
`qcore/sentiment.py` 已内置台账，从部署日起自动积累。

### O5 ★★★☆☆ 政策事件的"利空出尽"

实测最值得追的一条：**集采事件后医药板块 h=5 收益 −1.90%，t = −4.78，胜率 0.00**
——注意这是**反向**：公告后医药反而涨，即"利空出尽"。

**但样本只有 5 个**，且板块代理口径可疑（池子里没有地产，医药代理用的是化学制药+医疗服务，
而集采真正的受害者是仿制药小票）。**这是线索，不是结论。**

### O6 ★★☆☆☆ 资金流：实测无效，但分层思路可留

个股主力净流入对 5 日收益 **IC −0.003，t = −0.10**（94 个交易日）——基本无预测力。
原因：主力买所以涨，是**同期相关**而非领先信号。

真正可能有信息量的是**跨层级资金迁移**（ETF 份额变化、板块轮动、龙虎榜席位），
但这些数据要么拿不到历史（ETF 份额），要么接口不稳（两融）。已在 `qcore/capital.py` 标注。

## 三、当前市场状态（决策参考）

运行 `python -m qcore.brief` 生成当日快照。关键维度：

| 维度 | 怎么看 | 阈值含义 |
|---|---|---|
| 市场状态 regime | 4 档：跌低波/跌高波/涨低波/涨高波 | 分状态统计的 IC 差异明显，不要跨状态套用 |
| 距 250 日高点 | 回撤深度 | < −20% 进入统计上的"反弹高发区" |
| 波动分位 | 自身 250 日分位 | > 0.8 时信号噪声显著放大 |
| 成交额排名 | 点对点池的依据 | 排名骤降 = 流动性风险 |
| 散户情绪一致性 | > 0.6 且多空比 > 2 | 反向指标触发，**但只能前向验证** |

## 四、决策矩阵：什么条件下做什么

| 条件 | 动作 |
|---|---|
| IC 的 HAC t < 2 且不显著 | **不表态**（空仓或持有基准）。这不是保守，是纪律 |
| IC 显著为负（当前状态） | 可小仓位反向验证，**但必须先用独立样本复核** |
| 扣成本后净 IR < 0 | **不做**。有预测力不等于能赚钱 |
| 学习器跑不赢等权集成 | **回退等权**。学习器无效 |
| 有效独立信号 < 45 | 不要相信"多信号分散"，先做去重 |
| 相对"当日池等权"的超额为负 | 此前所有超额都是生存者偏差，**结论全部作废** |

---

## 五、什么情况下应该关掉这个系统

1. **连续 6 个月**，相对"当日池等权"的超额 ≤ 0，且滚动 IC 的 HAC t 一直落在 [−2, 2] 内。
2. 数据源出现无法修复的口径变化（例如复权方式再次变更且无替代源）。
3. 实盘与模拟盘的跟踪误差年化 > 20%（说明执行层漏得比 alpha 多）。
4. 参数敏感性检验出现"孤峰"（相邻参数点指标断崖式变化）——那是过拟合的确诊信号。

## 六、一句话总结

> **这个系统的正确用法：把它当成一台"风险测量仪"，
> 用它告诉你"现在有没有优势、优势有多大、还能不能信、什么时候该停手"。
> 它现在告诉你的答案是：技术指标没有优势，人性与事件可能有，但证据还不够。
> 在证据够之前，最好的操作是不操作。**
